The Problem
Fragmented Campus Experience
Pain Points

🍽️ Mess Disconnect

Students have no real-time visibility into weekly dining menus. Feedback is lost in verbal complaints, leaving mess managers with zero actionable quality metrics.

📢 Club Chaos

Important event announcements, registrations, and club recruitment get buried across dozens of chaotic WhatsApp and Telegram groups with high noise ratios.

🛒 Unsafe Commerce

Buying/selling textbooks, cycles, and lab kits relies on unmoderated chat spam without verified student identities, ratings, or organized chat trails.

The core issue: Crucial daily student utilities are scattered and unorganized. Slide 2 / 10

Security & Governance
Strict Role-Based Access (RBAC)
Security

🎓 Student

Access all student hubs, register for events, rate meals, post & buy items on CampusCart, chat with peers.

🏆 Club Lead

Create and manage club events, monitor attendee lists, broadcast official announcements to members.

👨‍🍳 Mess Admin

Publish meal menus, post urgent dining circulars, review real-time student rating metrics and sentiment.

🛡️ App Admin

Supervise total system state, user roles, audit trails, and moderate flagged CampusCart listings.

Zero Trust Security: Every backend controller endpoint is safeguarded with NestJS Guards, JWT token authentication, and role validation decorators.

Clean separation of concerns keeps data secure and organized. Slide 5 / 10
System Architecture
Modern & Resilient Tech Stack
Engineering

🖥️ Frontend Client

Stack: React 19, TanStack Start & Router, Vite, Tailwind CSS, Radix UI.

Perks: High-speed client-side routing, responsive UI, accessible design primitives, and optimistic updates.

⚙️ Backend Monolith

Stack: NestJS 12, TypeScript, RESTful API Gateway, Swagger / OpenAPI.

Perks: Enterprise modular architecture, DTO validation with class-validator, comprehensive error filters.

🗄️ Persistence & Mobile

Stack: PostgreSQL, Prisma ORM, Expo / React Native.

Perks: Type-safe database queries, automated SQL migrations, relational indexing, and mobile push readiness.

Modular design allows effortless scaling to thousands of active campus users. Slide 6 / 10

Advantages
